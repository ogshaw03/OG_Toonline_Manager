# OG Toonline Manager

Maya 用の輪郭線（トゥーンアウトライン）生成・管理ツールです。
輪郭線を**実ジオメトリ**で作るので、ビューポートでも各種レンダラー（Arnold / V-Ray / Redshift 等）でも同じ見た目で出ます。
元メッシュの**変形・移動に自動追従**し、太さ・色・曲率を **UI でライブ調整**＆**アニメーション**できます。

## 動作環境

Autodesk Maya（PySide6 / PySide2 両対応 ／ 2025 含む）

## 起動

`OG_Toonline_Manager.py` を Maya の `scripts` フォルダに置き、スクリプトエディタ（Python）で実行します。

```python
import OG_Toonline_Manager
OG_Toonline_Manager.show()
```

シェルフボタンに登録すると便利です。

## 使い方

**作る**
- メッシュを選んで **「選択メッシュに輪郭を生成」** … メッシュ全体の輪郭
- エッジを選んで **「選択エッジにライン」** … エッジに沿ったチューブ状ライン

**整理する**（中央のリスト）
- チェックで表示／非表示、ダブルクリックで名前変更、Delete キーで削除
- **「新規グループ」** で整理、ドラッグ＆ドロップでグループへ移動
- **「再取得」** … 別シーンや再起動後に既存ラインを管理下に戻す

**調整する**（ラインを選ぶと表示）
- **太さ** / **曲率起伏**（曲がる所ほど太く）/ **曲率上限**（太りすぎ防止）
- **太さプロファイル**（エッジのみ）… 長手方向の太さ強弱カーブ
- **全体倍率・グループ倍率** … まとめて太さを増減
- **色** … 共通カラー、またはライン個別カラー
- 各スライダーの **↺** で初期値に戻す

**アニメーション**
- スライダー横の **K** でキー打ち、ラインを選ぶとタイムスライダにキーが表示されます。

## オプション（下部）

- **ラインをビューポートで選択不可にする**（既定 ON）… 作業中に元メッシュを選びやすく
- **デフォーマハンドルをアウトライナーから隠す**（既定 ON）

## 表示されないとき

太さ・全体倍率・グループ倍率が 0 になっていないか確認してください。
別シーンを開いた後は **「再取得」** を押すと操作できます。
