# OG Toonline Manager

Maya 用の輪郭線（トゥーンアウトライン）生成・管理ツールです。
`dx11Shader` の輪郭線（MayaToonOutline.fx）のような見た目を、**Maya 標準の実ジオメトリだけ**で再現します。
ビューポート表示でも各種レンダラー（Arnold / V-Ray / Redshift など）でも、同じ輪郭が出ます。

- 元メッシュの**変形・移動・回転・スケールに自動追従**します。
- 太さ・色・曲率などを **UI でライブ調整**でき、**アニメーション**も可能です。

---

## 動作環境

- Autodesk Maya（PySide6 / PySide2 のどちらにも対応）
- Windows / macOS / Linux

---

## インストール / 起動

1. `OG_Toonline_Manager.py` を任意のフォルダに置きます。
2. Maya の **スクリプトエディタ（Python タブ）** に以下を貼り付けて実行します。
   `フォルダのパス` は `OG_Toonline_Manager.py` を置いた場所に書き換えてください。

```python
import sys
sys.path.append(r"C:/path/to/folder")   # OG_Toonline_Manager.py を置いたフォルダ

import OG_Toonline_Manager
# すでに読み込み済みのときに最新へ更新する場合（任意）
try:
    import importlib
    importlib.reload(OG_Toonline_Manager)
except Exception:
    pass

OG_Toonline_Manager.show()
```

よく使う場合は、上記を **シェルフボタン** に登録しておくとワンクリックで起動できます。
ウィンドウは何度起動しても 1 つだけ開きます（重複しません）。

## 基本的な使い方

### 1. 輪郭を作る

- **メッシュの輪郭（背面法）**
  メッシュを選択して **「選択メッシュに輪郭を生成」** を押します。
  メッシュ全体を包む輪郭線が作られ、元メッシュの変形・移動に追従します。

- **エッジに沿ったライン（チューブ）**
  ポリゴンのエッジを選択して **「選択エッジにライン」** を押します。
  選んだエッジに沿ったチューブ状のラインが作られます。

どちらも生成直後は決まった初期値で作られます。

### 2. ライン／グループの管理

- 作成したラインは中央のリストに一覧表示されます。`[背面]` / `[エッジ]` で種類が分かります。
- **チェックボックス**で表示／非表示を切り替えできます。
- **「新規グループ」** でグループを作り、ラインを整理できます。
- **ドラッグ＆ドロップ**でラインをグループへ移動できます。
- 項目を**ダブルクリック**すると名前を変更できます。
- 項目を選んで **Delete キー**で削除できます。
- **「再取得」** は、別のシーンや再起動後に既存のラインを UI の管理下に戻すときに使います。

### 3. 太さ・形状の調整

ラインを選ぶと、下部に調整スライダーが表示されます。

- **太さ** … ラインの太さ。
- **曲率起伏** … 曲がっている所ほど太く、まっすぐな所ほど細くします。
- **曲率上限** … 起伏の最大倍率（角が太くなりすぎないように上限を設定）。
- **太さプロファイル**（エッジライン選択時のみ） … 線の長手方向で太さに強弱をつけられるカーブ。
  左クリックで点の追加／移動、右クリックで点の削除ができます。

各スライダーの **↺** で初期値に戻せます。

### 4. グループ倍率・全体倍率

- 最上部の **全体倍率** で、すべてのラインの太さをまとめて拡大・縮小できます。
- グループを選ぶと **グループ倍率** が表示され、そのグループ内のラインの太さをまとめて変えられます。
- 太さは「ラインの太さ × グループ倍率 × 全体倍率」で決まります。

### 5. 色

- **「選択を共通カラーへ」** … 選んだラインを共通の色（既定は黒）にします。
- **「選択に個別カラー」** … 選んだラインだけ別の色にできます。

## アニメーション

太さ・曲率などはアニメーション可能です。

- 各スライダー横の **K ボタン**で、その値に現在フレームのキーを打てます。
- UI でラインを選ぶと対応するコントローラーが選択され、**タイムスライダにキーフレームが表示**されます。
- 数値欄はキーの状態に応じて色が変わります（アニメーションあり＝ピンク／現在フレームがキー＝赤）。
- 全体倍率の **「選択」** ボタンで全体コントローラーを選択でき、全体倍率のキーをタイムスライダで確認できます。

---

## オプション（下部のチェックボックス）

- **デフォーマハンドルをアウトライナーから隠す**（既定 ON）
  生成時に作られる補助オブジェクトをアウトライナーから隠します。
- **ラインをビューポートで選択不可にする**（既定 ON）
  ラインがビューポートでクリック選択されないようにします（表示・レンダーは有効）。
  作業中に元メッシュを選びやすくなります。OFF にすると通常どおり選択できます。

---

## ヒント

- 輪郭が表示されないときは、太さが 0 になっていないか、全体倍率／グループ倍率が 0 になっていないかを確認してください。
- 別シーンを開いた後やウィンドウを開き直した後は、**「再取得」** を押すと既存のラインを操作できます。
