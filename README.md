# OG Toonline Manager

Maya 用の輪郭線（トゥーンアウトライン）生成・管理ツールです。
輪郭線を**実ジオメトリ**で作るので、ビューポートでも各種レンダラー（Arnold / V-Ray / Redshift 等）でも同じ見た目で出ます。
元メッシュの**変形・移動に自動追従**し、太さ・色・曲率を **UI でライブ調整**＆**アニメーション**できます。

## 動作環境

Autodesk Maya（PySide6 / PySide2 両対応 ／ 2025 含む）

## インストール（かんたん・推奨）

`OG_Toonline_Manager_install.py` を Maya のビューポートに**ドラッグ&ドロップ**するだけ。

1. `OG_Toonline_Manager_install.py` をダウンロード（GitHub の raw URL をブラウザ保存）
2. Maya のビューポートにドラッグ → セットアップ完了ダイアログ
3. シェルフに **`OGToon`** ボタンが追加される（**左クリックで起動**）

Maya の再起動は不要です。**Maya 2022 以降（Python 3）** が対象です。

## アップデート（Maya 再起動なし）

GitHub に新しい版が出たら、次のどちらかで最新版に更新できます。

- ツール UI 下部の **「GitHub から更新」** ボタン
- シェルフ **`OGToon`** ボタンを**右クリック → Update from GitHub**

更新後はウィンドウが自動で開き直り、タイトル/フッターのバージョン表示が変わります。

## 手動で起動する場合

`OG_Toonline_Manager.py` を Maya の `scripts` フォルダに置き、スクリプトエディタ（Python）で実行します。

```python
import OG_Toonline_Manager
OG_Toonline_Manager.show()
```

シェルフボタンに登録すると便利です。

英語UI版（機能は同じ・同じシーンノードを操作）は `OG_Toonline_Manager_EN.py` を使います。

```python
import OG_Toonline_Manager_EN
OG_Toonline_Manager_EN.show()
```

## 使い方

**作る**
- メッシュを選んで **「選択メッシュに輪郭を生成」** … メッシュ全体の輪郭（背面法）
- エッジを選んで **「選択エッジにライン」** … エッジに沿ったチューブ状ライン
- ハルラインを選んで **「隙間埋め」** … 背面法ハルがグラジング角でフチが浮いて見える隙間を、
  別オブジェクト（線色）で塞ぐ。カメラに対して寝た面（シルエット）の頂点だけベースのライン位置まで
  押し出し、正面の面は表面に張り付かせる。カメラ依存・レイ不要で軽く、VP2/バッチ対応。トグルで追加/削除。

**整理する**（中央のリスト）
- チェックで表示／非表示、ダブルクリックで名前変更、Delete キーで削除
- **「新規グループ」** で整理、ドラッグ＆ドロップでグループへ移動
- **「再取得」** … 別シーンや再起動後に既存ラインを管理下に戻す

**調整する**（ラインを選ぶと表示）
- **太さ** / **曲率起伏**（曲がる所ほど太く）/ **曲率上限**（太りすぎ防止）
- **太さプロファイル**（エッジのみ）… 長手方向の太さ強弱カーブ
- **全体倍率・グループ倍率** … まとめて太さを増減
- **色** … 共通カラー、またはライン個別カラー
- 各スライダーの **↺** で初期値に戻す

**アニメーション**
- スライダー横の **K** でキー打ち、ラインを選ぶとタイムスライダにキーが表示されます。

## オプション（下部）

- **ラインをビューポートで選択不可にする**（既定 ON）… 作業中に元メッシュを選びやすく
- **デフォーマハンドルをアウトライナーから隠す**（既定 ON）

## 表示されないとき

太さ・全体倍率・グループ倍率が 0 になっていないか確認してください。
別シーンを開いた後は **「再取得」** を押すと操作できます。

## 関連ツール: Follow Face Patch

選択したポリゴンフェースを複製し、元メッシュの変形・移動に追従する独立メッシュ
（パッチ）を作るツールです（`Follow_Face_Patch.py`）。Maya の押し出しなどと同じく、
生成後も**ヒストリ（チャンネルボックスの `followOffset`）から法線方向オフセットを調整**できます。

```python
import Follow_Face_Patch
Follow_Face_Patch.show()
```

フェースを選択して「選択フェースを複製して追従パッチを作成」を押すと、選択フェースだけの
パッチが元メッシュに追従します。オフセットは UI スライダー、または各パッチの
`followOffset` 属性で調整します。
